# Delta Traders - React + Tailwind CSS Web Application

## Setup & Running Locally
1. Unzip the folder: `unzip delta-traders-react.zip`
2. Navigate into the folder: `cd delta-traders-react`
3. Install dependencies: `npm install`
4. Start development server: `npm run dev`
5. Open browser at `http://localhost:5173`

## Production Build
```bash
npm run build
```
Generates a static `dist/` folder ready to deploy on Vercel, Netlify, or any web host.
